# 🤖 AI Multi-Chat Application

A modern, responsive multi-agent AI chat application built using Next.js App Router, React, Tailwind CSS, Clerk Authentication, and Firebase.

---

## 🌐 Live Demo

* **Deployment URL:** [ai-multi-chat-eight.vercel.app](https://ai-multi-chat-eight.vercel.app)

---

## 🛠️ Key Features

* **Multi-Agent Chat Architecture:** Interact with distinct AI personas and agents.
* **Authentication:** Secure user login and user state management powered by Clerk (`@clerk/nextjs`).
* **Database & Storage:** Real-time chat history and data persistence using Firebase.
* **Modern UI/UX:** Dark/Light theme switching (`next-themes`), Radix UI primitives, Lucide icons, and Tailwind CSS.
* **Rich Text Support:** Markdown formatting with `react-markdown` and `remark-gfm`.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router), React
* **Language:** TypeScript
* **Styling:** Tailwind CSS, Framer Motion
* **Authentication:** Clerk
* **Database:** Firebase
* **Security & Shielding:** Arcjet (`@arcjet/next`)

---

## 🚀 How to Run

1. **Clone the repository:**
   `git clone https://github.com/DavronbekBuxdu123/ai-multi-chat.git`
   `cd ai-multi-chat`

2. **Install dependencies:**
   `npm install`

3. **Set up environment variables:**
   Create a `.env.local` file in the root directory and configure your Clerk, Firebase, and Arcjet keys.

4. **Run the development server:**
   `npm run dev`
